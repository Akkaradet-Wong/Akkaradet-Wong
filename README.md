### 📌 ผลงานเด่น (Featured Projects)

#### 📱 [Mobile Application Development](https://github.com/Akkaradet-Wong/Mobile-Application-Development)
> คลังผลงานการพัฒนาแอปพลิเคชันมือถือ (Flutter & Dart) รวบรวมผลงานตั้งแต่ Lab 01 ถึง Lab 09
- **ฟีเจอร์เด่น:**
  - เชื่อมต่อ REST API ดึงสถิติสดแบบ Asynchronous (COVID-19 Live Tracker)
  - ระบบระบุพิกัดดาวเทียม GPS และเรนเดอร์แผนที่อินเทอร์แอคทีฟ (OpenStreetMap + Geolocator)
  - เข้าถึงฮาร์ดแวร์กล้องถ่ายรูป สั่นเตือน และบันทึกลงแกลเลอรี (Camera + Gallery Saver)
  - ระบบบันทึกข้อมูลประวัตินักศึกษาลง Local Storage ด้วย `path_provider`
  - โคลน UI แถบแจ้งเตือนระดับมือถือ (Samsung/Android Quick Settings)
- **Tech Stack:** `Flutter`, `Dart`, `REST API`, `Geolocator`, `OpenStreetMap`, `Camera`

#### 🌐 [JSW-KOL-Platfrom](https://github.com/Akkaradet-Wong/JSW-KOL-Platfrom)
> แพลตฟอร์มเว็บสำหรับลงทะเบียนและจัดการบัญชี KOL รองรับระบบตรวจสอบข้อมูลฟอร์มแบบ Multi-step
- **ฟีเจอร์เด่น:**
  - การตรวจสอบความถูกต้องของข้อมูล (Form Validation) ทั้งอีเมล, รหัสผ่าน, และเบอร์โทรศัพท์
  - ระบบสมัครสมาชิกแบบหลายขั้นตอน (Multi-step Registration)
  - ดีไซน์สวยงาม ทันสมัย และตอบสนองต่อทุกขนาดหน้าจอ (Responsive Design)
- **Tech Stack:** `React`, `TypeScript`, `Vite`, `Tailwind CSS`, `Oxlint`
